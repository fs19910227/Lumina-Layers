# 色彩制式与选色

## 各模式槽位

### 2 色 BW

白、黑。

### 4 色

| 制式 | 四卷料 |
|------|--------|
| **CMYW** | 白、青、品红、黄 |
| **RYBW** | 白、红、黄、蓝 |

注意：青 ≠ 淡蓝；品红 ≠ 浅粉，应接近印刷青/品红。

### 6 色

在四色思路上再加 **绿 + 黑**：

- **CMYWGK**：青、品红、黄、白、绿、黑
- **RYBWGK**：红、黄、蓝、白、绿、黑

### 8 色

| 槽 | 颜色 |
|----|------|
| 1 | 白 |
| 2 | 青 |
| 3 | 品红 |
| 4 | 黄 |
| 5 | 黑 |
| 6 | 红 |
| 7 | 深蓝 / 克莱因蓝 |
| 8 | 绿 |

软件预览绿约 **RGB (0,174,66) / `#00AE42`**，偏柠檬绿/嫩绿，不是墨绿。各品牌预设色名可能写「柠檬绿」「嫩绿」「草绿」，以实打校准为准。

## 怎么选色数（人像/婚纱向）

| 需求 | 建议 |
|------|------|
| 先 stylize 的装饰画 | **6 色通常够**；8 色非刚需 |
| 粉裙 + 大面积绿植 | 6 色 **CMYWGK** 更稳 |
| 酒红裙 + 海蓝 | 6 色 **RYBWGK** 更稳 |
| 只要粉白、背景可简化 | 4 色 CMYW 可试 |
| 强红蓝对比、少绿 | 4 色 RYBW 可试 |

加色数能拓宽色域、改善暗部/绿叶，**救不了写真级连续肤色**。

## 相近色顶替

- 用别人预设 + 自己「差不多」的线 → 容易偏色  
- 用自己的料打板、自己提 `.npy` → 自洽，可以用  
- 长期正解仍是本机校准
