# 校准与背板相关坑

## `.npy` 从哪来

「校准板生成」只出 **3MF**，不会直接出 `.npy`。

完整链路：生成色卡 3MF → 打印 → 拍照 → **颜色提取** → 下载 `.npy` → 图像转换里选用。

## 色块尺寸 / 间隙

只影响板子物理大小和是否好拍、好取样，**不改变**有哪些叠色配方。新手用默认（约 5 mm 色块 + ~0.8 mm 间隙）即可。

## 背板颜色：能选但链路不完整（1.x）

| 步骤 | 实际情况 |
|------|----------|
| 校准板生成 | 下拉可选 White/Cyan/Magenta/Yellow/Red/Blue |
| 颜色提取 | 按**白背板**引导（点白角、参考图写死白底） |
| 图像转换 | 代码写死 `backing_color_name = "White"` |

因此：选黄背板能打出黄底色卡，提取界面却按白引导，出图又强制白背 → **半成品功能 / UX 坑**。

底层 `generate_final_model(..., backing_color_name=...)` 其实支持非白；缺的是 UI 接上。提取算法本身只采样照片 RGB，**不必**在提取页再选背板；要改的是转换页背板可选，并与校准一致。

### 6/8 色更坑

6 色 / 8 色 / 5 色扩展生成时 **忽略** 背板下拉，体素里写死白底（slot 0）。界面仍显示可选，等于无效。

### CMYW 下可选红/蓝

背板下拉未按模式过滤。CMYW 的 `color_map` 没有 Red/Blue 时，`get(..., 0)` 会 **静默落成白**。

## 实测偏粉案例要点

黄背板 + 品红叠色会整体偏暖粉；拍照白平衡差会进一步加重。  
重打建议：背板 White、模式与耗材槽一致、白角在左上、自然光 + 开自动白平衡再提取。

## 朝上打印校准板

整板刚体翻转后，相对观赏面的叠序一般仍对；但观赏面变顶面，纹理/取色通常更差。默认仍建议彩面朝下，优先调象脚与首层。

## 上游 Issue

截至整理时，未看到专门「非白背板全链路」的 issue；有批量转换时 `Backing color: False` 一类相关日志（如 [#157](https://github.com/lumina-layer-studio/Lumina-Layers/issues/157)）。值得单独提 bug。
