# 人像与照片质感限制

## 难点判断

写实人像（含婚纱照）经 Lumina 后常出现：

- 肤色发粉 / 发灰 / 发蜡  
- 脸部分块，像油画或海报  
- 色彩细节拉到 256 也难「自然」

这主要是 **叠色色域 + 离散 LUT 查表** 的上限，其次才是量化参数。

## 管线如何毁掉「照片感」

1. K-Means 等量化 → 皮肤连续渐变被收成平涂块  
2. Lab 最近邻进有限 LUT（四色约 1024 档）→ 再吸到「能打出的叠法」  
3. CMYW/RYBW 等色域对细腻米色/橙粉肤色覆盖差  

算法可减轻色带，但 **变不成喷墨写真**。官方示例也更偏插画、表情包、高对比图。

## 换思路：先 stylize 再叠色

把写真收成适合叠色的语言，观感通常明显好转（目标变成「能打的装饰画」，不是还原照片）：

- 赛璐璐 / 厚涂：脸部分明暗 2～4 块  
- 波普 / 海报 / 版画感  
- 背景虚化或大色块，去掉密叶、细浪等高频纹理  
- Lumina 里色彩细节试 **24～64** 即可，不必 256  

## 婚纱样张选型备忘

| 题材 | 更合适 |
|------|--------|
| 粉裙 + 绿树 | 6 色 CMYWGK；或 stylize 后 4 色 CMYW 且弱化绿背景 |
| 酒红裙 + 海 | 6 色 RYBWGK |
| 8 色 | 非刚需 |

## 和全彩 / 后处理的关系

- FDM 多色（AMS）是离散切色，不是体素喷墨全彩  
- 真全彩看 Mimaki / PolyJet / 彩色粘结剂等外包  
- 白模 + 底漆 + 喷漆/喷笔/水贴，人像可控性往往好过硬叠色追照片  
- 喷实底漆后，耗材原色基本不重要；重要的是表面处理
