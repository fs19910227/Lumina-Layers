# 核心原理与生成管线

## 叠色在做什么

不是喷墨全彩，而是：

1. 半透明耗材按固定层高叠若干层（1.x 默认 **5 × 0.08 mm ≈ 0.4 mm**）
2. 光线穿过层叠后，人眼看到混合色
3. 底下再加不透明背板（默认约 1.6 mm，常用白）

四色时穷举 \(4^5 = 1024\) 种叠法，打成校准板，拍照得到 LUT（`.npy`），转图时用 Lab 最近邻查表，再按配方填体素导出多材料 3MF。

**5 层不是物理公式算出来的唯一解**，是 1.x 写死的工程常数（组合数、板子大小、透光厚度的折中）。2.0 在探索自定义层数/层高，但叠色物理仍是这一套。

## 关键约定（Face-Down）

- **Z=0** = 观赏面 = 贴床先打的颜色层
- 背板在颜色层「上面」（打印坐标系里）
- 打完翻过来看彩色面

校准板和图像转换默认都是彩面朝下，不是导出反了。

## 端到端管线

```text
校准板生成 → 打印色卡 → 拍照
    → 颜色提取 → .npy LUT
    → 图像匹配（量化 + Lab 查表）
    → 体素堆叠 → 按材料拆 mesh → 3MF
```

`.npy` 通常只存实测 RGB 网格；叠法由色块序号按四进制规则反推（合并 LUT 的 `.npz` 会显式带 stacks）。

## 3MF

3MF 是通用 ZIP+XML 格式。Lumina 额外写入 Bambu/Orca 风格 `Metadata/`，方便直接打开。几何通用；耗材映射与工艺参数依赖切片器是否认这些扩展。

## 自研时最小闭环建议

只做：常用色数（如 CMYW 四色）+ 白背板 + 单面朝下 + 出 3MF。  
生成与出图的背板颜色必须一致。许可证为 GPL-3.0，搬代码再分发需注意传染性。
